前のいくつかの演習では、ユーザー エクスペリエンスの改善や機能の追加を目的とする 3 つのタスクを Copilot クラウド エージェントに依頼しました。クラウド エージェントは非同期かつ自律的に動作しますが、タスクを監視することも重要です。

クラウド エージェントに割り当てたタスクを管理するツールは複数あります。その 1 つが GitHub.com の[エージェント ページ][agents-page]です。このミッション コントロールでは、オープンなプルリクエスト（PR）があるすべてのエージェント タスクを確認できます。実行された操作を調べたり、進行中のセッションの方向付けをしたりできます。

このレッスンでは、次のことを行います。

- エージェント ページでクラウド エージェントのタスクを監視します。
- 進行中のセッションの方向を変え、機能の追加を依頼します。

## シナリオ

ハイ コントラスト モードの作成をエージェントに割り当てた後、チームはライト モードも追加する良い機会だと考えました。サイトのスタイルと切り替え機能をすでに更新しているため、同じ作業に含めるのが自然です。エージェントに作業の方向を示し、ハイ コントラスト モードに加えてライト モードも追加してもらいます。

## Copilot クラウド エージェントのタスクを確認する

Copilot クラウド エージェントに割り当てたすべてのタスクの現在の状態を確認しましょう。

1. [Copilot エージェント ページ](https://github.com/copilot/agents)に移動します。
2. メイン ペインと左ペインの両方に表示されるタスクの一覧を確認します。Copilot に割り当てた次のタスクが表示されます。
    - コードベースのドキュメントの更新。
    - ゲームを変更するための API の生成。
    - Web サイトへのハイ コントラスト モードの追加。
3. 実行中のタスクを 1 つ選択します。Copilot が実行したタスクを確認します。次のような操作が含まれる場合があります。
    - リポジトリからコードをチェックアウトする。
    - Copilot が作業する環境を作成する。
    - MCP サーバーをセットアップする。
    - 割り当てられたタスクを完了するためのさまざまな手順を実行する。

> [!NOTE]
> 表示される手順は、Copilot の作業状況や採用したアプローチによって異なります。

4. 右側に表示されるプルリクエスト（PR）ペインも確認してください。追加の監視に役立つ PR と変更ファイルが表示されます。

## クラウド エージェントの方向を調整する

実行中のタスクを確認できたので、Copilot がハイ コントラスト モードを作業する間に、ライト モードの切り替えも追加するよう依頼します。

1. ハイ コントラスト モードを追加するセッションを選択します。正確なタイトルは、Copilot が選んだ名前や現在の作業状況によって異なります。

    ![ミッション コントロールでのアクセシビリティ セッション](../../../_images/ex6-accessibility-session.png)

2. セットアップが完了し、作業を開始したことが示されるまで、数分間セッションを確認します。以下のようなメッセージが表示されたら、作業が始まっています。
3. **Steer active session while Copilot is working** ダイアログで、次のプロンプトを入力します。

    ```plaintext
    While we are working on a high contrast mode, let's also add a light mode. There should be a switch for this mode as well where users can select their desired display mode.
    ```

    ![Copilot が作業中のエージェント ページで、作業中セッションの方向付け用ダイアログが強調表示されたスクリーンショット](../../../_images/ex6-steer-cloud-agent-task.png)

4. <kbd>Enter</kbd> を押してプロンプトを送信します。
5. Copilot がプロンプトを受け取り、作業に取り入れることを確認します。

## Copilot に作業を任せる

前回と同様に、Copilot が更新されたタスクに取りかかります。メッセージを送信した時点で作業していた手順が終わると、新しい依頼が作業の流れに反映されます。

今回も数分かかります。これまでに学んだことや確認したことを振り返りましょう。

## まとめと次のステップ

このレッスンでは、GitHub Copilot クラウド エージェントのタスクを監視して方向付ける中心的な場所である、Copilot エージェント ページについて学びました。このミッション コントロールでは、進行中や完了したすべてのタスクを追跡し、実行中の作業を確認して、進行中のタスクの方向を変更したり追加のガイダンスを提供したりできます。

次の概念を確認しました。

- ミッション コントロールとエージェント ページで、クラウド エージェントのタスクを監視する方法。
- 進行中のセッションの方向を変えて、機能の追加を依頼する方法。
