Explora GitHub Copilot a lo largo del ciclo de vida del desarrollo de software mediante escenarios realistas, una aplicación completa y un backlog compartido. Trabajarás de forma iterativa para planificar cambios, crear código, probar su comportamiento, revisar solicitudes de incorporación de cambios y gestionar el trabajo con agentes.

## Escenario

Eres un nuevo desarrollador de Tailspin Toys, una empresa ficticia que ofrece financiación colectiva para juegos de mesa con temática de desarrollo. El backlog del equipo ya está registrado como incidencias de GitHub, listas para que te ocupes de ellas. Incluye tareas de funcionalidad, como el filtrado y la paginación, y mejoras de calidad, como la accesibilidad y los estándares de programación.

## Elige tu entorno

GitHub Copilot está disponible allá donde trabajes. Elige el entorno que mejor se adapte a tu forma de desarrollar. Cada taller empieza con su propia configuración y usa el escenario compartido de Tailspin Toys.

### [GitHub Copilot CLI][cli]

Usa el asistente con agentes desde el terminal. Trabaja con los modos Plan y Autopilot, instrucciones, habilidades, agentes personalizados, Playwright MCP, Agent Merge y prácticos comandos de barra.

### [GitHub Copilot app][app]

Ejecuta sesiones de agentes en paralelo, cambia de modo, colabora en lienzos y administra incidencias y solicitudes de incorporación de cambios de GitHub desde la aplicación de escritorio.

### [GitHub Copilot cloud agent][cloud]

Asigna incidencias de GitHub a un agente asíncrono, orienta su trabajo, supervisa su progreso y revisa las solicitudes de incorporación de cambios que abra.

### [Visual Studio Code][vscode]

Usa GitHub Copilot en Visual Studio Code y GitHub Codespaces. Trabaja con el modo agente de Copilot Chat, servidores MCP y agentes personalizados sin salir del editor.
